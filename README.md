# git

## 快速开始

```bash
git clone git@github.com:youyudexigua111/git.git
cd git
```

## 目录结构

```
.
```

## 约定

- 主分支：`main`
- 提交信息参考 [Conventional Commits](https://www.conventionalcommits.org/)：`feat:` / `fix:` / `docs:` / `chore:`
- 本地工具状态目录 `.workbuddy/` 不入库
